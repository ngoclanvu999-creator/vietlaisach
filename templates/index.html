🏭 Lò Soạn Đề AI — Ngân hàng câu hỏi

AI soạn đề mới, nhưng không câu nào vào ngân hàng nếu chưa qua đủ 3 lớp thẩm định: kiểm tra cấu trúc → bắt AI giải lại độc lập (giấu đáp án) → đối chiếu số bằng sympy. Câu bị loại vẫn hiện kèm lý do để bạn biết AI sai ở đâu.
Đang tải ngân hàng...

Mỗi lượt soạn tốn 2 lượt gọi API (1 soạn + 1 giải lại đối chiếu), không phụ thuộc số câu. Gói Gemini miễn phí cho 20 lượt/ngày.

⚠️ Trên bản Web, ngân hàng bị xóa mỗi lần deploy lại (đĩa máy chủ là tạm). Hãy tải về để giữ công soạn đề.

🚀 Hướng Dẫn Triển Khai Web (Cloud Deployment)

Ứng dụng đã được tích hợp sẵn Dockerfile, requirements.txt và host binding 0.0.0.0, sẵn sàng triển khai 1-click lên bất kỳ dịch vụ Cloud nào:

1. Triển khai qua Docker

docker build -t bien-soan-sach .
docker run -p 8501:8501 bien-soan-sach

2. Triển khai Render.com / Railway / Cloud Run

Build Command: pip install -r requirements.txt

Start Command: python app.py hoặc uvicorn app:app --host 0.0.0.0 --port $PORT

3. Triển khai VPS Linux (Ubuntu / Debian)

git clone <repo>
pip install -r requirements.txt
nohup python app.py &
